## Coin-Finding Game
Description : 
This is a simple Python game built using Pygame. The objective of the game is to find a hidden coin on a grid. 
The game includes multiple levels, and players must find the coin within a limited number of tries. Upon finding the coin, the game progresses to the next level. 
If the player runs out of tries, the game ends. A congratulatory message is displayed when all levels are completed.
